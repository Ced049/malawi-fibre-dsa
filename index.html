The scenario

Each node is a district town and each edge a planned fibre-optic cable link. The weight is the approximate cable length in kilometres (illustrative planning figures). The graph is undirected, weighted and connected.

Dijkstra finds the shortest cable route between two towns (for example the lowest-latency path for data). A minimum spanning tree is the cheapest set of 23 links that still connects all 24 towns, i.e. the lowest-cost way to roll out the backbone.

Source code: data.js, graph.js, dijkstra.js, mst.js, tests.js (inlined in this page).
