# Malawi Fibre-Optic Backbone: Dijkstra and MST

JavaScript implementation of Dijkstra, Kruskal and Prim on a 24-node Malawi network.

- Open index.html in any browser (no installation).
- Optional: `node test/run.js` runs the 22 tests.
